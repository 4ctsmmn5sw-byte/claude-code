# 明日の設計

明日やることを、00:00〜24:00 の縦型タイムライン上で **分単位** に設計する Web アプリです。
**スマートフォンの縦画面を基準に設計** しており、PC でも同じ 1 カラムの縦型時間割を中央に表示します。

> ⚠️ **データはこのブラウザの localStorage にだけ保存されます。別の端末・別のブラウザには自動で同期されません。**
> ブラウザのサイトデータを消去すると、タスク・固定予定・設定も消えます。

## 画面構成

```
┌──────────────────────────┐
│ ‹  10月15日（木）明日  › ⚙ │ ← 固定ヘッダー（日付・前日/翌日・設定）
│ [今日][明日]     − 100% + │ ← 表示倍率
├──────────────────────────┤
│ 08:00 ┃ ジムで筋トレ        │
│ 09:00 ┃ 🔒 大学（斜線）      │ ← ここだけ縦スクロール
│  ...                     │
├──────────────────────────┤
│ ━━  未配置タスク 2件 引き上げる │ ← 引き上げ可能なシート
├──────────────────────────┤
│  予定     （＋）    タスク  │ ← 最下部の操作（ホームインジケーター分の余白あり）
└──────────────────────────┘
```

- 横並び 2 カラムは使いません。ヘッダーと下部の操作領域は固定で、タイムラインだけが縦スクロールします
- 初期表示日は **明日**（Asia/Tokyo 基準）
- 最初の表示位置は、その日の予定のまとまりが画面に収まるなら全体が中央に来る位置、収まらなければ最初の予定の 30 分前。今日なら現在時刻の 1 時間前、予定がなければ 8:00
- 下部シートは上端のバーを上下にドラッグ（またはタップ）して開閉。「タスク」で開き、「予定」で下げる
- 中央の「＋」でタスクを追加（時間は未配置のまま登録）
- `viewport-fit=cover` と `env(safe-area-inset-*)` で、iPhone のノッチ・ホームインジケーターと操作が重ならない
- ボタンやタップ対象は原則 44px 以上。高さが小さい予定（例：10 分＝15px）も上下に広げた 44px の当たり判定でタップできる

## タッチ操作

| 操作 | 動作 |
| --- | --- |
| 上下スワイプ | タイムラインのスクロール |
| 約 300ms の長押し → 移動 | ドラッグ（300ms 前に 8px 以上動いたらスクロール扱い） |
| 未配置タスクを長押し | ドラッグ開始と同時に下部の一覧が縮小し、タイムラインを広く使える |
| ドラッグ中 | 画面上部に開始〜終了時刻を常に表示。配置先に点線の枠。重なる場合は赤色 |
| 表示領域の上下端に近づける | タイムラインが自動スクロール（下端は「シートの上端」が基準）。シートから掴んだ直後は、指が一度端から離れるまで自動スクロールしない |
| タイムライン外で離す・タッチのキャンセル・重なる位置で離す | 保存せず元の位置に戻す（一覧の開閉状態も元に戻す） |
| 配置済みタスクを下部シートへ | 未配置に戻す |
| 未配置タスクをタップ → 時間割の空き時間をタップ | **タップで配置**（代替操作）。開始時刻は吸着単位で切り捨て |
| 配置済みタスクをタップ | 選択（下端に長さ変更ハンドル、下部に「編集・完了・未配置へ・閉じる」）。もう一度タップで編集 |
| 固定予定をタップ | 「この日だけ休みにする」「毎週の予定を編集する」「毎週の繰り返しを終了する」 |

- 重なる場合は赤く表示して配置を防止します。**ユーザーの確認なしに別の時刻へずらすことはしません**
- マウスでは 4px 動かすとドラッグ開始（クリックは選択・編集）

## 時間調整

- ドラッグ・伸縮・タップ配置の吸着単位は標準 5 分。設定で 1 分に変更可
- 選択中のタスクの下端ハンドル（当たり判定 44px）で長さを変更（Pointer Events + `setPointerCapture`）。伸縮中は開始〜終了と分数を表示し、重なると赤く表示して離しても元の長さに戻す
- 編集画面で **開始時刻・終了時刻・所要時間** を 1 分単位で直接入力（開始を変えると所要時間を保って終了が動き、終了を変えると所要時間が変わる）
- 表示倍率は 50%〜200%（1 分あたり 0.75〜3px）。倍率を変えても画面中央の時刻が同じ位置に残る。200% では 30 分・15 分の補助線も表示

## 固定予定

- 設定画面で、予定名・毎週繰り返す曜日（複数選択、「平日」「土日」「毎日」）・開始時刻・終了時刻・**適用開始日・適用終了日**・色を登録
- タイムラインでは鍵マーク＋斜線＋落ち着いた色で表示し、タスク（明るい色）と区別。ドラッグでは動かない
- 固定予定は日付ごとにコピーせず **「曜日の規則」として 1 件だけ保存** し、表示する日にその場で展開
- 「この日だけ休みにする」は規則の `skipDates`（例外日）に日付を足すだけで、**毎週の設定全体には影響しない**。休みの日は点線で薄く表示され、タップで取り消せる（設定画面からも取り消し可）。休みにした直後はトーストの「元に戻す」でも戻せる
- 「毎週の予定を編集する」は設定画面のその予定の編集を開き、変更はすべての週に反映（休みにした日は保持）
- 「毎週の繰り返しを終了する」は「この日まで表示して翌週から終了」か「この日から終了」を選び、適用終了日を設定するだけ（過去の表示・予定データは残る。トーストの「元に戻す」で取り消し可）
- 固定予定の変更で既存タスクと重なった場合、タスクは自動で動かさず赤枠と「他の予定と重複しています」で知らせる。設定画面で曜日・時刻・期間を変えて重なる場合は、保存前に重なる予定を一覧で警告する

### 通常のタスクを毎週の固定予定にする

- タスクをタップ → 編集画面の「繰り返し設定」で「毎週繰り返す」を選ぶと、予定名・開始時刻・終了時刻・繰り返す曜日（月〜日の複数選択）・繰り返し開始日・繰り返し終了日（未指定可）・予定の色を設定できる
  - 初期値は、曜日＝そのタスクの日の曜日、開始日＝その日、色＝タスクの色に近い固定予定用の色
- 保存すると既存の固定予定の仕組み（曜日の規則 1 件）として登録され、**元のタスクは同じ保存処理の中で削除**されるので重複して残らない。日付ごとの複製は作らない
- 例：「国際コミュニケーション論」を毎週水曜 9:00〜10:40 にすると、開始日以降のすべての水曜（終了日まで）に鍵マーク付きで表示される
- 他のタスクや固定予定と重なる場合は保存前に警告し（「重なりを確認して毎週の予定にする」）、重なる予定は削除・移動しない
- 保存直後のトーストの「元に戻す」で、元のタスクに戻せる
- 保存データの形式は変わらない（v2 のまま）。既存のタスク・固定予定・設定はそのまま読み込める

## データ

localStorage のキー `asu-no-sekkei:v1` に次の形で保存します（v1 形式のデータは読み込み時に v2 へ自動変換）。

```ts
{
  schemaVersion: 2,
  tasks: [{ id, title, durationMin, color, done, date /* YYYY-MM-DD | null */, startMin /* 0〜1440 | null */, createdAt, updatedAt }],
  fixedEvents: [{ id, title, weekdays /* 0=日〜6=土 */, startMin, endMin, color, validFrom, validTo, skipDates, createdAt, updatedAt }],
  settings: { snapMinutes: 5 | 1, pxPerMinute: 0.75 | 1 | 1.5 | 2 | 3 }
}
```

- 時刻はすべて 0:00 からの経過分（整数）。座標 → 時刻は `(clientY − タイムライン本体の getBoundingClientRect().top) ÷ 倍率` で換算するため、スクロール位置・倍率・画面サイズに依存しない
- ドロップ時は「最後にプレビューを計算した座標」を同じ関数で確定するので、表示された時刻と保存される時刻が一致する
- 読み込み時に項目ごとに検証し、壊れた項目だけ除外。全体が読めなくても画面は壊れず、元データは `asu-no-sekkei:v1:backup:<時刻>` に退避
- 保存は `Repository` インターフェース（`lib/storage.ts`）の裏にあり、クラウド保存へ差し替えやすい構造

## 技術構成

- Next.js 16（App Router）/ React 19 / TypeScript / Tailwind CSS v4
- ドラッグ＆ドロップ：[`@dnd-kit/react`](https://dndkit.com/react) 0.5（`PointerSensor` の活性化条件：タッチ＝300ms 長押し、マウス＝4px 移動。標準の `AutoScroller` は外し、下部シートを考慮した自動スクロールを自前で実装）
- 長さ変更・シートの引き上げ：Pointer Events
- テスト：Vitest（ロジック）、Playwright（iPhone 14 サイズのタッチ操作、PC のマウス操作、日付）

```
app/            page.tsx（タイムライン）, settings/page.tsx（固定予定・設定）
components/     Planner（ドラッグ・自動スクロール・選択の中心）, Timeline, TimelineTaskBlock, TaskSheet（下部シート）,
                BottomNav, Header, TaskDialog, AddTaskSheet, FixedEventSheet, SettingsView, Modal, TimeInput, Toast
hooks/          useTokyoClock, useToast
lib/            types, time（分変換・吸着・倍率）, date（JST・曜日）, schedule（重複判定・固定予定の展開）,
                storage（Repository・検証・移行）, store（状態と保存）, colors
tests/          Vitest
e2e/            Playwright
```

## 開発

```bash
npm install
npm run dev        # http://localhost:3000 （スマホから開く場合は同じ LAN の IP で）
npm run build
npm run lint
npm test           # Vitest
npm run test:e2e   # Playwright（先に npm run build。ポート 3100 で next start を起動）
```
