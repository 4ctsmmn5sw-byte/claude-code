# 明日の設計

明日やることを、00:00〜24:00 の縦型タイムライン上で **分単位** に設計する Web アプリです。
曜日ごとの固定予定（大学・アルバイトなど）が自動で表示され、その空き時間にタスクをドラッグ＆ドロップで配置します。

> ⚠️ **データはこのブラウザの localStorage にだけ保存されます。別の端末・別のブラウザには自動で同期されません。**
> ブラウザのサイトデータを消去すると、タスク・固定予定・設定も消えます。

## 機能

### 画面
- PC：左に「未配置タスク」、右に「1日の縦型タイムライン」の 2 カラム
- スマートフォン：タイムラインを優先表示し、未配置タスクは下部のシートで開閉
- タイムラインは 00:00〜24:00 をスクロール。1 時間ごとの時刻ラベルと 30 分ごとの補助線、今日を表示しているときは現在時刻の線
- 画面上部に日付、前日／翌日、「今日」「明日」ボタン。**初期表示は明日**

### タスク
- 名前・予定所要時間（分）・色・完了状態・配置日・開始時刻を持つ
- 追加時は時間未配置で登録され、左の一覧に並ぶ
- 未配置タスクをタイムラインへドラッグ → 予定に変換
- 配置済みタスクをドラッグ → 時刻変更（掴んだ位置を保ったまま移動）
- タスク下端のハンドル → 長さ変更（Pointer Events で実装）
- ドラッグ中は配置先の時刻をプレビュー表示。**離した時刻＝プレビューの時刻** で保存される
- ドラッグの刻みは標準 5 分、設定で 1 分に変更可
- 編集ダイアログで開始・終了時刻を 1 分単位で直接入力（「930」「9:30」「24:00」などを受け付け）
- 未配置に戻す（ダイアログのボタン、またはタスクを左の一覧へドラッグ）・編集・削除・完了
- スマートフォンは **長押し（約 0.2 秒）でドラッグ開始**。素早いスワイプは通常のスクロール、タップで編集

### 固定予定
- 設定画面で、名前・開始時刻・終了時刻・色・曜日（複数選択、「平日」「土日」「毎日」の一括指定あり）を登録
- 例：月曜と水曜の 9:00〜12:00 に「大学」→ 毎週月曜・水曜のタイムラインに自動表示
- タスクとは別の落ち着いた色＋斜線＋鍵アイコンで表示し、ドラッグできない
- 固定予定は **日付ごとにコピーせず「曜日の規則」として 1 件だけ保存** し、表示する日の曜日から展開する。
  変更すると該当曜日の将来の表示すべてに反映される
- 固定予定を後から変更して既存タスクと重なった場合、タスクは自動で動かさず赤枠と「重複 n件」で知らせる

### 時間の扱い
- すべての時刻を 0:00 からの経過分（0〜1440 の整数）に正規化して位置・長さを計算
- 座標 → 時刻は `clientY − タイムライン本体の getBoundingClientRect().top` から換算するため、
  スクロール位置・画面サイズ・自動スクロール中でも正しい時刻になる（`lib/time.ts` の `pointerToStartMinutes`）
- 固定予定・他のタスクと重なる配置、0:00〜24:00 を超える配置は警告し保存しない（ストア側でも必ず検証）
- 日付と曜日は **Asia/Tokyo** 基準。端末が別のタイムゾーンでも東京の日付で「今日」「明日」を判定し、
  日付をまたぐと（30 秒ごと・タブ復帰時に再判定）表示が更新される

### 保存
- localStorage のキー `asu-no-sekkei:v1` に `{ schemaVersion, tasks, fixedEvents, settings }` を保存
- 読み込み時に項目ごとに検証し、壊れた項目だけを除外。全体が読めない場合も画面は壊れず空の状態で始まり、
  元のデータは `asu-no-sekkei:v1:backup:<時刻>` に退避される
- 保存処理は `Repository` インターフェース（`lib/storage.ts`）の裏に隠してあり、
  クラウド保存に移す場合は同じインターフェースを実装して差し替えられる。データは ID・ISO 日時付きの素の JSON

## 技術構成
- Next.js 16（App Router）/ React 19 / TypeScript / Tailwind CSS v4
- ドラッグ＆ドロップ：[`@dnd-kit/react`](https://dndkit.com/react) 0.5（`DragDropProvider`・`useDraggable`・`DragOverlay`、
  `PointerSensor` の活性化条件をマウス＝4px 移動／タッチ＝長押しに設定）
- 長さ変更：Pointer Events（`setPointerCapture`）
- テスト：Vitest（ロジック）、Playwright（実ブラウザでのドラッグ・タッチ・日付）

```
app/            page.tsx（タイムライン）, settings/page.tsx（固定予定・設定）
components/     Planner（ドラッグ処理の中心）, Timeline, TimelineTaskBlock, TaskPanel, TaskDialog, SettingsView, ...
hooks/          useTokyoClock（東京の今日・現在時刻）, useToast
lib/            types, time（分変換・刻み）, date（JST・曜日）, schedule（重複判定・固定予定展開）,
                storage（Repository・検証）, store（状態と保存）, colors
tests/          Vitest
e2e/            Playwright
```

## 開発

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run lint
npm test           # Vitest
npm run test:e2e   # Playwright（先に npm run build が必要。ポート 3100 で next start を起動）
```
